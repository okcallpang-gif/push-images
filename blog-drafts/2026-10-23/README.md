각 폴더에는 draft.txt, images/01~05, captions.txt가 있습니다. 같은 사진을 여러 문단에서 사용한 원고는 해당 순서에 맞춰 원본을 반복 배치했습니다. 원고 안의 소제목 다음 출처 문구는 해당 사진 아래에 넣을 캡션입니다. TXT는 메모장에서 열 수 있는 UTF-8 파일입니다.
